# Сайт Виктории Мыльниковой

Персональный сайт: креативный маркетолог / Marketing Director.

Стек: статический HTML + CSS + JavaScript без сборки и npm-зависимостей.
Внешний ресурс один — шрифты Google Fonts (Cormorant Garamond, Manrope).

## Как открыть сайт на Mac

**Запуск:** двойной клик по **Victoria Portfolio.app** — сайт откроется в браузере по адресу http://localhost:8765/.

**Остановка:** двойной клик по **Victoria Portfolio Stop.app**.

- Оба приложения можно перетащить на Рабочий стол или в «Программы» — они продолжат работать.
- Сайт работает в фоне, пока его не остановить или не перезагрузить Mac. Браузер можно закрывать и открывать снова — адрес http://localhost:8765/ продолжит открываться.
- Повторный двойной клик по Victoria Portfolio.app просто снова откроет сайт.
- **С телефона:** подключите телефон к той же Wi-Fi-сети, что и Mac, и откройте `http://<адрес Mac>:8765/`. Адрес Mac: «Системные настройки» → Wi-Fi → «Подробнее…» у текущей сети → IP-адрес. Адрес может меняться при смене сети. Сайт виден только устройствам в этой же сети, не в интернете.
- Без интернета сайт тоже откроется, но шрифты Google Fonts заменятся системными, пока шрифты не перенесены в `assets/fonts`.

Если папка проекта когда-нибудь будет перенесена, приложения нужно держать внутри неё (или обновить путь в `Victoria Portfolio.app/Contents/MacOS/start-server`). Журнал сервера: `~/Library/Logs/VictoriaPortfolio/server.log`.

## Структура

```
Victoria Portfolio.app   запуск сайта на Mac двойным кликом (сервер в фоне, без Terminal)
Victoria Portfolio Stop.app  остановка сайта
index.html               главная: hero, обо мне, экспертиза, кейсы, подход, отзывы, контакты
pages/cases/case.html    шаблон страницы кейса: case.html?slug=<slug>
css/style.css            дизайн-токены (:root) и все стили
js/config.js             публичная конфигурация и флаги функций
js/dom.js                безопасные DOM-хелперы (только textContent)
js/api.js                слой доступа к данным — единственная точка чтения контента
js/main.js               шапка и меню, анимации появления, рендер секций из content/, форма
js/case-detail.js        рендер подробной страницы кейса
content/                 редактируемый контент: site.js (контакты, hero, обо мне, экспертиза, подход), кейсы, отзывы
assets/images|icons|fonts  медиа; фото кейсов — assets/images/cases/<slug>/
server/                  backend (FastAPI): сайт + /api, заявки в SQLite, email — см. раздел Backend
```

## Дизайн-система

Все параметры в `:root` в начале `css/style.css`.

| Цвет | Значение | Роль |
|---|---|---|
| Ivory | `#F7F4EE` | основной фон |
| Graphite | `#171717` | текст, крупная типографика, основные кнопки |
| Emerald | `#087F6A` | акцент: hover, фокус, мета-подписи кейсов |
| Muted Gold | `#C5A46D` | редкий декор: линии у номеров разделов, отзывов |

Компоненты используют семантические переменные (`--color-accent`, `--color-decor`…), а не сырые цвета — баланс ~80% ivory/graphite сохраняется сам собой.

Брейкпоинты (mobile-first): 640 / 960 / 1280 px; навигация в шапке становится горизонтальной с 1024 px.

Тёмные блоки (финальный CTA, подвал) используют класс `.inverse`: он переопределяет те же семантические переменные, поэтому компоненты перекрашиваются сами. Анимации появления включаются только при работающем JS и отключаются при `prefers-reduced-motion`.

## Контент

Контент не зашит в разметку. Кейсы, отзывы и контакты лежат в `content/*.js`, страницы читают их только через `js/api.js`. Когда появится backend с админ-панелью, функции в `api.js` переключатся на `fetch('/api/...')` с теми же сигнатурами — рендер менять не придётся.

**Изображения** указываются путём от корня сайта (`assets/images/...`) — `VM.dom.asset()` разрешает его одинаково с главной и со страницы кейса. Схемы всех полей описаны в шапке каждого файла `content/*.js`.

**Добавить кейс:** заполнить поля в `content/cases.js` (схема описана в шапке файла) и поставить `status: 'published'` — карточка станет ссылкой. Черновики видны в списке, но не кликабельны; их страницу можно проверить напрямую, например `pages/cases/case.html?slug=logistics`.

Кейсы, результаты, цифры и отзывы добавляются только из материалов клиента.

## Форма заявки

Имя, телефон, сообщение — обязательны. Проверка на клиенте и отдельно на сервере. Форма отправляет `POST /api/leads`; после успеха — «Спасибо! Сообщение отправлено.», форма очищается; при ошибке — просьба повторить или связаться напрямую. Во время отправки кнопка заблокирована, повторная отправка той же заявки не создаёт дубль.

## Backend

Один процесс отдаёт и сайт, и API на http://localhost:8765/ — его запускает Victoria Portfolio.app (FastAPI + Uvicorn, Python-окружение в `server/.venv`).

| Что | Где |
|---|---|
| Код | `server/app/` — `main.py` (приложение), `api/` (эндпоинты), `repositories/` (SQL), `services/` (email), `schemas.py` (валидация) |
| База заявок | `server/data/leads.db` (SQLite, таблица `leads`: id, name, phone, message, status `new`/`contacted`/`closed`, notification_status, created_at) |
| Настройки и секреты | `server/.env` (не публикуется и не отдаётся сайтом); образец — `server/.env.example` |
| Журнал | `~/Library/Logs/VictoriaPortfolio/server.log` |

**API:** `GET /api/health` → `{"status":"ok"}` (проверка: открыть http://localhost:8765/api/health в браузере); `POST /api/leads` → `201 {"success": true}`, ошибки валидации → `422`, слишком частые заявки → `429`, внутренняя ошибка → `500` без технических деталей.

**Email.** По умолчанию `EMAIL_ENABLED=false` (режим разработки): заявка сохраняется в базе, в журнал пишется «email disabled», письмо не отправляется. Чтобы включить уведомления на Mylnikova.Viktoria.job@yandex.ru:

1. скопировать `server/.env.example` в `server/.env`;
2. заполнить `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURITY`, `SMTP_USER`, `SMTP_PASSWORD` (для Яндекса — пароль приложения), при необходимости `LEAD_EMAIL_FROM`;
3. поставить `EMAIL_ENABLED=true`;
4. перезапустить сайт: Victoria Portfolio Stop.app → Victoria Portfolio.app.

Сайт отдаёт только публичные файлы (`index.html`, `favicon.ico`, `css/`, `js/`, `content/`, `assets/`, `pages/`); папка `server/`, база и `.env` по адресу недоступны.

Восстановить окружение, если папка `server/.venv` удалена (для разработчика): `python3 -m venv server/.venv && server/.venv/bin/pip install -r server/requirements.txt`.
